# Inversión Básica (Educativo)

> **Advertencia:** Este documento es únicamente educativo. No recomienda instrumentos específicos ni promete rendimientos. Antes de invertir, consulta a un asesor financiero certificado.

## Conceptos básicos

### ¿Qué es invertir?

Invertir es destinar dinero a un instrumento financiero o activo con la expectativa de obtener un rendimiento futuro. Todas las inversiones implican algún nivel de riesgo.

### Relación riesgo-rendimiento

Generalmente:

- Mayor rendimiento esperado = mayor riesgo.
- Menor riesgo = menor rendimiento esperado.

## Instrumentos comunes en México

| Instrumento | Riesgo | Liquidez | Notas |
|-------------|--------|----------|-------|
| Cuenta de ahorro | Muy bajo | Alta | Rendimiento bajo o nulo |
| CETES | Bajo | Media | Valores gubernamentales |
| Bonos | Bajo-Medio | Media | Deuda de gobierno/empresas |
| Fondos de inversión | Variable | Alta | Diversificación |
| Acciones | Alto | Alta | Propiedad parcial de empresas |
| Bienes raíces | Medio-Alto | Baja | Requiere capital importante |

## Pasos antes de invertir

1. Tener un fondo de emergencia completo.
2. Pagar deudas de alto interés.
3. Definir objetivos y plazos.
4. Conocer tu perfil de riesgo.
5. Diversificar.
6. Invertir solo dinero que no necesites a corto plazo.

## Perfiles de riesgo

- **Conservador:** Prefiere seguridad, acepta rendimientos bajos.
- **Moderado:** Acepta algo de riesgo para mejores rendimientos.
- **Agresivo:** Busca altos rendimientos, tolera pérdidas significativas.

## Reglas básicas

- No inviertas en lo que no entiendas.
- Diversifica entre instrumentos, sectores y plazos.
- Piensa a largo plazo.
- Revisa periódicamente, pero no reacciones a cada fluctuación.
